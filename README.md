# «Рассвет»

Закрытое веб-приложение (PWA) для подросткового служения церкви «Вифания» (Гродно): листок недели, вопрос недели, встречи и объявления, «Написать лидеру». До 30 человек. Безопасность несовершеннолетних — обязательное требование, поэтому все права проверяет база (RLS), а не экран.

> Это **демо** с вымышленными людьми: https://dkloban-ctrl.github.io/rassvet-demo/

## Как устроено

```
app/, components/, lib/        приложение: Next.js (статический экспорт) + Tailwind
public/                        манифест PWA, service worker, иконки
supabase/migrations/           схема, RLS, функции, журнал
supabase/tests/                189 тестов прав (pgTAP)
supabase/functions/            регистрация по приглашению, сброс пароля подростка, рассылка уведомлений
docs/permissions.md            матрица прав — читать первой
scripts/local-test/            прогон SQL-тестов без Supabase CLI, проверка шифрования пушей
scripts/setup-secrets.ts       ключи VAPID и прочие секреты для Vault
```

## Уведомления

Публикация листка, вопроса или объявления и сообщение в ящике лидеров кладут задание в очередь (`notification_outbox`). Очередь разбирает функция `send-notifications`: база будит её сразу после публикации (pg_net) и раз в 5 минут (pg_cron — отложенные публикации и повторы после сбоев). Web Push реализован на WebCrypto без внешних библиотек и проверен эталонной расшифровкой (`scripts/local-test/webpush.check.ts`).

- Кому слать, решает база (`notify_recipients`) — те же роли и статусы, что и RLS, плюс личные настройки («Ещё» → «Уведомления»).
- В пуше нет имён и текстов из ящика: экран блокировки видят другие.
- Одно уведомление на листок/вопрос/объявление, даже если его правили.
- Лидеры видят статус рассылки в админке: 🔔 сколько ушло, ✉ сколько писем.
- iPhone: пуши работают только в приложении, установленном на экран «Домой» (iOS 16.4+).
- Письмо родителям о новом листке — через Resend: секреты функции `RESEND_API_KEY`, `EMAIL_FROM` (нужен свой домен, например vifania.by). Без них пуши работают, письма пропускаются.

Приложение — набор статических файлов. Оно ходит в Supabase с публичным ключом; что кому можно, решают политики RLS и функции базы. Поэтому его можно хостить где угодно (GitHub Pages, Vercel, свой домен).

## Роли

| | Видит | Может |
|---|---|---|
| Подросток | листок, вопрос, ответы ребят (анонимные — без имени), встречи, свои обращения | отвечать (с именем или «анонимно для ребят»), писать лидерам |
| Помощник (17) | то же, автора анонимного ответа — нет | — (модерация чата — этап 2) |
| Родитель | листок, текст вопроса, встречи, своих детей | подписать/отозвать согласие, сбросить пароль ребёнку, запросить приглашение; читать обращения ребёнка — только если лидер открыл, только новые, ребёнок это видит |
| Лидер | всё, включая автора анонимных ответов | публиковать, приглашать, активировать, открывать доступы; всё пишется в журнал |

## Запуск у себя

```bash
npm install
cp .env.example .env.local        # URL и publishable-ключ проекта Supabase
npm run dev                       # http://localhost:3000
```

Сборка для GitHub Pages: `NEXT_PUBLIC_BASE_PATH=/rassvet-demo npm run build` → папка `out/`.

## Перед настоящим запуском

1. Supabase → Authentication → Sign In / Providers → **выключить «Allow new users to sign up»**: аккаунты только по приглашению.
2. Минимальная длина пароля — 8.
3. Свой проект Supabase (не демо), миграции из `supabase/migrations`, функции из `supabase/functions`, секреты функций `ALLOWED_ORIGINS` и `APP_URL` с адресом сайта.
4. Секреты в Vault: `node --experimental-strip-types scripts/setup-secrets.ts <project-ref> <mailto:… или https://сайт>` → выполнить напечатанный SQL. Это ключи VAPID, пароль для пробуждения рассылки и **ключ регистрации**: с ним база пускает в Auth только пользователей, созданных по приглашению.
5. Ежедневная резервная копия базы (на бесплатном тарифе её нет).
6. Юридические вопросы (оператор данных, реквизиты согласия по Закону № 99-З, сервер в ЕС) — до приглашения реальных семей.

## Проверки

```bash
cd supabase/functions && deno test _shared/ && deno check */index.ts
npm i --no-save http_ece@1.2.0 && node --experimental-strip-types scripts/local-test/webpush.check.ts
npm run typecheck && npm run build
```
